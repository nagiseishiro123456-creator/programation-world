# Imágenes de referencia

Se conservan las 17 imágenes recibidas para la preproducción del juego. Los archivos se nombran por identificador para facilitar los enlaces; sus bytes no han cambiado. El nombre original y el hash SHA-256 de cada archivo están registrados en [manifest.json](manifest.json).

El Product Owner confirmó su generación con IA. La herramienta concreta, los materiales de entrada y las condiciones de uso siguen pendientes de documentar. Su inclusión en esta carga no aprueba todos los elementos que representan ni constituye una licencia para publicarlos.

Las referencias REF-04 y REF-05 contienen elementos de combate descartados. Se preservan los originales para trazabilidad; las entrevistas del juego serán conversaciones y retos técnicos en oficina. La primera versión educativa incluye institutos y universidades.

La revisión detallada y las decisiones están en [reference-review.md](../../docs/design/reference-review.md).
